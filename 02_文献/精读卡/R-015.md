# R-015 精读卡

> Xiangyu Qi et al. *Fine-tuning Aligned Language Models Compromises Safety, Even When Users Do Not Intend To!*. arXiv:2310.03693v1，2023-10-05。
> 核验状态：已读取完整摘要、§3–4.1、§4.4、§5.1、§6–7、附录 B 人工一致性部分、F、G；已检查攻击实验设置以区分有害与良性微调。页码为已存档 v1 PDF 页码，与论文印刷页码一致。

## 核心问题与主张

论文揭示开放微调权限的安全代价：显式有害示例、隐式身份诱导示例，以及用户无恶意的效用导向数据微调，均可能使已对齐模型的安全性下降。与本课题直接相关的是 §4.4 的良性微调和附录 F 的 LoRA 结果，而不是把恶意微调攻击当作良性现象的证据。

**关键边界**：文中 Alpaca 和 Dolly 被过滤掉了部分 safety-related 样本（附录 G.1）。所以准确表述应是“在作者处理过的效用导向数据上仍观测到退化”，不能写成“原样 Alpaca-cleaned 10k 或任意完全良性数据必然导致同幅度退化”。

## 方法

- 常规监督微调：对 system/user/assistant 单轮对话优化目标 assistant 回复的负对数似然。
- 主文 Llama-2 实验默认**全参数微调**，AdamW；GPT-3.5 Turbo 使用 0613 版本、当时 API 微调，作者主要控制 epochs。PEFT/LoRA 单独报告于附录 F。
- 同一数据条件的训练、基线安全评测、微调后安全评测使用相同 system prompt；不同数据集的基线有差异，不能跨表列直接归因于模型变化。
- GPT-4 judge 结合政策、用户请求、模型回答和评分标准给出 1–5 有害性分数。主文报告平均分，以及**恰获最高分 5 的比例**（harmfulness rate / high harmfulness rate）；这不是“拒绝率的补数”。
- 安全数据混合实验将 Bianchi et al. 的 harmful instruction/refusal 样本加入三个训练场景，测试 GPT-3.5 Turbo 的安全性；不追踪激活方向，不实施定向激活锚定。

## 数据/设置

| 项 | 原文设置 |
|---|---|
| 主模型 | Llama-2-7b-Chat；GPT-3.5 Turbo-0613 |
| 主有害评测 | 11 类 × 30 条 = 330 条，政策导向、作者构建；附录 E 另用公开 AdvBench |
| 主文良性微调 | 每数据集 1 epoch；Llama-2 全参 AdamW，lr `2e-5`，batch 128 |
| Alpaca | 原始约 52K；删去 1,902 条 safety-related 样本，约 50K 的 uncensored 版本 |
| Dolly | 删去 387 条 potentially safety-related 样本，保留 14,624 条 |
| LLaVA-Instruct | LLaVA-Instruct-80K，CLIP 视觉编码器；安全评测的视觉输入为 uniform noise |
| 良性 LoRA（附录 F） | Alpaca，AdamW，lr `1e-4`，batch 16，1 epoch；本次所读附录未给出 rank、alpha、target modules，不作猜测 |
| 生成随机性 | 文中设置 temperature 和 top-p 为 0 |

原文关键结果（均为作者报告，非本项目结果）：

| 条件 | 初始最高有害分率 | 微调后最高有害分率 | 定位 |
|---|---:|---:|---|
| GPT-3.5，Alpaca | 5.5% | 31.8% | Table 3，p8 |
| Llama-2 全参，Alpaca | 0.3% | 16.1% | Table 3，p8 |
| Llama-2 全参，Dolly | 0.6% | 12.1% | Table 3，p8 |
| Llama-2 LoRA，Alpaca | 0.3% | 25.2% | Table 11，p35 |

安全混合的良性场景：GPT-3.5 的 Alpaca 1 epoch，加入 0 / 250 / 500 / 1,000 条安全样本后，最高有害分率分别为 31.8% / 21.8% / 19.7% / 22.1%（Table 4，p11）。并非“越多必然越好”，也没有恢复到相应基线 5.5%。这不是固定 **5%** 混合比例或与本项目等训练 token 预算的直接验证。

## 证据强度

- 两个模型体系、多个效用导向数据集、全参和三种 PEFT，以及学习率/批量/epochs 消融支持“良性用途也可能发生安全退化”的存在性结论。
- 附录 F 对本课题的 LoRA 背景最直接，但只覆盖 Llama-2-7b-Chat 和作者版 Alpaca；不足以保证 Qwen2.5-7B + Alpaca-cleaned 10k 的复现效应。
- 附录 B（p28–30）报告 4 名作者的人评：500 条按 judge 分数 1–5 均衡抽样；100 条共同校准，后续 400 条各由一位评者标注。多级 Cohen's κ=0.539，Spearman ρ=0.84；以分数 3 为界的二值 κ=0.792。这个二值阈值**不同于**主 harmfulness rate 的“分数 5”。这些数字不能替换为“85–90% accuracy”，也不能直接沿用到 HarmBench/Llama Guard。
- 人评校准阶段讨论了 GPT-4 的推理，评者又是作者；均衡抽样不是自然分布代表样本，因此一致性证据有明确设计边界。

## 局限

1. “良性”指用户无恶意的效用导向训练场景；Alpaca/Dolly 中安全相关样本被移除。需要本项目显式记录是否采用原版、cleaned 或同样过滤。
2. 没有机制追踪，灾难遗忘/目标张力是可能解释而非被证明的因果机制。
3. 基线依赖 system prompt；微调超参也显著影响退化。更高学习率、小 batch 常使退化增强；更多 epochs 不一定单调增害。
4. 安全混合的完整 safety–utility trade-off 明确超出研究范围，不能支撑“几乎不损效用”。
5. 主 330 条政策评测与当时的 API 模型/政策有时代和发布限制；论文 v1 未公开部分原始数据和回答。不能声称已完全复现其私有基准。

## 与本课题关联

- **C-3 已核验成立但需限缩。** 安全混合确可缓解作者测试条件下的退化，尚未恢复初始水平，且非固定 5% 的受控基线比较。
- Brief 的“完全良性 Alpaca”应改为准确数据处理描述；将未经安全移除的数据和去除安全样本的数据混称会掩盖重要混杂。
- 支持把 benign LoRA 安全退化作为待复现现象；不支持预先认定 Qwen2.5 上必然≥10 pt，也不支持投影下降机制。
- protocol 必须独立记录数据过滤、prompt、微调方法、judge 阈值；将“有害遵从”和“缺少拒绝短语”分别处理。
