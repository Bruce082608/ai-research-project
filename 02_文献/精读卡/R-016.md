# R-016 — Safe LoRA

- 完整题名：Safe LoRA: the Silver Lining of Reducing Safety Risks when Fine-tuning Large Language Models
- 作者：Chia-Yi Hsu、Yu-Lin Tsai、Chih-Hsun Lin、Pin-Yu Chen、Chia-Mu Yu、Chun-Ying Huang。
- 版本与来源：arXiv:2405.16833v2；首次发布 2024-05-27，所读 PDF 标注 v2 / 2025-01-05、NeurIPS 2024；[摘要](https://arxiv.org/abs/2405.16833v2)、[PDF](https://arxiv.org/pdf/2405.16833v2)。读取日期 2026-09-08。
- 本地原文：[PDF](../原文/R-016_2405.16833v2.pdf)、[逐页文本](../原文/R-016_2405.16833v2.txt)。已读摘要、§3–§5、主实验表；附录未逐项精读，代码未运行。以下页码为 PDF 页码。

## 核心主张

对完成普通 LoRA 微调的权重更新做事后投影，可以在部分微调场景下降低安全退化并保留任务效用。它是**事后、权重空间、需要 base/aligned 成对模型**的方法，不是训练中的激活方向损失。

> “Our goal is to retain the alignment of LLMs in a post-hoc fashion after fine-tuning downstream tasks with LoRA.”（p.4，§3）

> “It is worth noting that Safe LoRA is a training-free and data-free approach, as it only requires the knowledge of the weights from the base and aligned LLMs.”（p.1，摘要）

“无需数据/训练”指补丁的应用，不表示上游 LoRA 不需要训练或方法完全无额外存储成本。

## 方法

每个权重矩阵取 `V = W_aligned − W_unaligned`（默认官方 base 与 chat/instruct 权重），由此构造投影矩阵。§3.1 Eq.2 写出 `Ĉ = V(VᵀV)⁻¹Vᵀ`；§3.4 为节省计算使用近似 `C = VVᵀ / ||V||F`。比较原始 LoRA 更新 `ΔW` 与投影后 `CΔW` 的 Frobenius 余弦相似度，低于阈值 τ 的权重更新才投影；也可预设投影最低相似度的 K 个更新矩阵（p.4–5，§3.2，Eq.3）。

不能把文中 `C` 与标准正交投影无条件视为同一算子；实现时应按版本明确选择，并核验作者代码。文中报告 H100 上单次矩阵构造约 0.0086 s 对 2.1714 s（p.5，§3.4），不是完整训练节省时间。

## 数据与设置

- 模型：主实验 Llama-2-7B-Chat、Llama-3-8B-Instruct；附录 Gemma 结果本卡未核验。
- PureBad：100 条恶意示例；Dialog Summary：抽 1,000 条训练样本，恶意混合条件另加 100 条 PureBad；摘要任务测试 200 条。Alpaca：原文称总计 50,098 条，其中 200 条验证，未额外加入恶意样本（p.6，§4）。
- LoRA：`q_proj/v_proj`，rank 8；Llama-2 学习率 5e-5、batch 5、5 epochs。Llama-3 的不同数据任务另设学习率/轮数（p.6）。
- 安全分数：GPT-4 对 11 类问题打 1–5 分，低为安全。ASR 是是否缺少拒绝关键词，**不是语义行为完成率**。效用：摘要 ROUGE-1 F1；PureBad/Alpaca 用 MT-Bench（p.6）。

## 证据强度

已读主表支持其在所列模型/数据上有实测改进：

| 场景 | LoRA | Safe LoRA | 定位 |
|---|---:|---:|---|
| Llama-2 + PureBad：有害分数 / MT-Bench / ASR | 4.66 / 4.54 / 95.76% | 1.055 / 6.34 / 3.03% | p.7，Table 2 |
| Llama-2 + 良性 Alpaca：有害分数 / MT-Bench / ASR | 2.25 / 5.06 / 86.67% | 1.09 / 5.62 / 6.67% | p.8，Table 4 |
| Llama-2 + 纯良性摘要：有害分数 / ROUGE-1 / ASR | 1.27 / 49.57% / 9.70% | 1.061 / 50.96% / 3.94% | p.8，Table 3 |

原文也报告 Llama-3 + 良性摘要的 ROUGE-1 从普通 LoRA 49.04% 降为 Safe LoRA 47.64%，因此“完全不损效用”不成立（p.8，Table 3）。对 Llama-3 的 Alpaca 条件作者不报告主表结果，理由是在适当学习率下 ASR 仅上升约 3%，增大学习率会显著损效用（p.8，Alpaca 段）。这是本项目不可预设所有模型均明显退化的重要证据。

## 局限

- 需要同架构的未对齐/已对齐模型权重；两者差异同时含指令跟随和对齐成分，不能直接等同于纯“拒绝方向”。
- ASR 依赖拒绝关键词，可能把“先拒绝后提供有害内容”或无拒绝但未完成行为误判。本项目不可与 HarmBench 语义 ASR 横向直接比较绝对值。
- 主实验表未列随机种子、标准差或置信区间；不能据点估计宣称稳定显著优势。
- 投影层数与安全/效用存在权衡；本项目若实现基线，应只在开发集选 τ/K。
- 作者明确提及未来自适应攻击可能绕过该方法（p.10，Broader Impact and Limitations）。未提供 Qwen2.5 系列可直接外推的实验证据。

## 与本课题关联

它是低开销安全保护的重要基线，可与训练时激活方向锚定比较；不应把“LoRA 后安全修复”作为新颖性。可区分点是：本课题固定拒绝激活方向、观察训练轨迹，并以随机方向/强度匹配对照检验特异性。以上是拟议差异，不是已证明优势，也不保证相对 R-037 或新近工作的创新成立。
