# R-014 精读卡

> Andy Arditi et al. *Refusal in Language Models Is Mediated by a Single Direction*. arXiv:2406.11717v3，2024-10-30 更新，NeurIPS 2024。
> 核验状态：已读取完整摘要、§2–4、§7、附录 A–C、I.2，并检索全文相关词；不是仅依据摘要的综述。以下页码均指已存档 v3 PDF 页码，与论文印刷页码一致。

## 核心问题与主张

作者研究已对齐聊天模型的拒绝行为是否有可干预的低维表示。对 13 个、规模 1.8B–72B 的聊天模型，找到一个均值差方向：从残差流中消除此方向可降低有害请求上的拒绝；向单层激活添加此方向可诱导模型拒绝无害请求。论文也用等价的权重正交化实施干预，并分析对抗后缀与方向传播的关系。

这提供的是“存在一个有效干预方向”的证据，不等于“拒绝只有一个方向”，也没有检验良性 LoRA 训练过程中方向是否被侵蚀。§7 明确把方法定位为 existence proof，并承认方向的语义可能是 harm、danger 或尚不可直释的概念。

## 方法

- 提取：在每层、每个 **post-instruction token**（chat template 中用户指令之后的 token）计算 harmful-minus-harmless 的残差流激活均值差 `r_i^l = mean(h_harm) - mean(h_harmless)`。并非所有模型都固定最后一个 token。
- 选择：对 `层 × post-instruction token` 候选使用独立验证集，计算消融后有害提示的平均 refusal metric（`bypass_score`）、添加后无害提示的该指标（`induce_score`）、消融在无害提示上造成的末 token 输出分布 KL（`kl_score`）。选取 `bypass_score` 最小且 `induce_score > 0`、`kl_score < 0.1`、`l < 0.8L` 的向量（§C.1，p21）。这些是论文启发式规则，不是本项目已批准参数。
- refusal metric 是拒绝起始 token 概率和的 log-odds，用于高效选向量；它不是最终有害遵从判定器。附录 B 还据此过滤提示；该筛选应记录，不能把筛选后的方向表现当作未经筛选全分布表现。
- 因果干预：directional ablation 使用单位向量，从所有层、所有 token 的相关残差状态中减去沿该向量的投影；activation addition 使用未单位化均值差向量，只在来源层、所有 token 上添加。对所有写入残差流的输出权重进行 rank-one 正交化与消融等价（§4.1）。
- 最终评测分别测拒绝和有害性：拒绝使用短语匹配；安全性使用 Llama Guard 2（safe=1）；HarmBench 对比使用该基准提供的判定器。拒绝率、安全率、ASR 不是同一标签的简单互补。

## 证据强度

- 多模型、双向激活干预和独立有害评测支持“所选方向可介导拒绝”的存在性主张；论文区分短语拒绝与实际有害输出，避免只靠拒绝关键词下结论。
- 表 2（p6）显示系统提示会实质影响结果：Llama-2 7B 的权重正交化 ASR 为默认系统提示下 22.6%、无系统提示下 79.9%；Qwen 7B 对应 79.2% / 74.8%。因此本项目必须锁定模板及系统提示。
- 表 3 和 §4.3（p7）显示部分常用效用指标变化较小，但 TruthfulQA 一致下降；不能概括为“所有能力无损”。论文也承认质量指标不完美。
- 本次全文检索及所读方法/实验中，**未找到随机激活方向安慰剂实验**；出现的 random suffix 是对抗后缀分析的输入对照。不能用本篇支撑 Brief 中“Arditi 报告随机方向不影响拒绝”的表述。

## 局限

1. 选方向涉及启发式阈值、模型相关起始拒绝 token、提示过滤和验证选择；单层固定位置的简化实现应被写成项目自定方法，而非声称完全复现。
2. 未测试 Qwen2.5 或 0.5B 模型；未跟踪良性训练 checkpoint；不支持微调投影下降的机制因果链。
3. 方向语义未定，且存在多个有效方向与本篇结果兼容；单方向锚定的负结果也不能直接推出拒绝表示与退化无关。
4. 对抗后缀机制分析仅单模型、单对抗例；质量评测并不覆盖所有有用行为。

## 与本课题关联

- **C-4：部分核验成立。** 早期 Qwen 家族有直接证据；对主模型 Qwen2.5-7B 的适用性改由 R-038 文献证据和后续独立方向验证共同支持。
- **C-6：本篇不支持。** 随机方向锚定仍是本项目待检验假设；不能把随机后缀对照转写为随机方向证据。
- direction extraction、direction selection、anchor prompts、最终 safety/utility test 应独立；方法应冻结 A 模型抽出的向量后再跟踪训练，避免重新抽向量造成坐标系改变。
- 需保持“拒绝”“安全”“有害遵从”三个概念的区别，并检测无害过度拒绝；仅稳定投影不能视为已恢复安全。
