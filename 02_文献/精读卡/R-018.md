# R-018 — Safety Alignment Should Be Made More Than Just a Few Tokens Deep

- 作者：Xiangyu Qi、Ashwinee Panda、Kaifeng Lyu、Xiao Ma、Subhrajit Roy、Ahmad Beirami、Prateek Mittal、Peter Henderson。
- 版本与来源：arXiv:2406.05946v1，2024-06-10；[摘要](https://arxiv.org/abs/2406.05946v1)、[PDF](https://arxiv.org/pdf/2406.05946v1)。读取日期 2026-09-08。
- 本地原文：[PDF](../原文/R-018_2406.05946v1.pdf)、[逐页文本](../原文/R-018_2406.05946v1.txt)。已读摘要、§2.1–2.2、§3–§4、附录 A.5 与 B；数学证明与全部攻击实验未逐项核验。页码为 PDF 页码。

## 核心主张

安全对齐对生成分布的改变可能主要集中在最初几个输出 token，因此开头分布的偏移可破坏后续拒绝；保护这些早期 token 的概率分布可以缓解微调安全退化。

> “Finally, we design a regularized finetuning objective that makes the safety alignment more persistent against fine-tuning attacks by constraining updates on initial tokens.”（arXiv 摘要全文；PDF p.1 对应摘要语句略有措辞差异）

> “Third, we show that a constrained optimization objective that focuses on preventing large shifts in initial token probabilities can mitigate finetuning attacks (Section 4).”（p.2，Introduction）

本篇**不仅是“浅层性背景”**，还直接提出训练时保护目标并评估良性下游微调，需要纳入方法差异表。

## 方法

两条路线应分开：

1. 安全恢复数据增强（p.6–8，§3）：把有害指令/有害回答前缀与安全拒绝拼接，让模型在已偏入有害轨迹时恢复拒绝；还用初始模型对 Alpaca 指令的蒸馏回答锚定效用。256 组三元组；k 以 50% 概率取 0，其余在 1–100 均匀采样；安全项权重 α=0.2。
2. Token-wise constrained SFT（p.8–10，§4，Eq.3）：对每个输出 token，用当前模型与冻结初始对齐模型的对数概率比构造 `−(2/βt) log sigmoid(βt log(πθ/πaligned))`，β 越大，对初始分布偏离的抑制越强。β₁=0.5、β₂…β₅=2、后续 β=0.1。该损失相当于根据分布偏移自适应缩小 CE 梯度，并非直接对残差激活做单方向 MSE。

## 数据与设置

- Llama-2-7B-Chat、Gemma-1.1-7B-IT；§4 对比 standard SFT 与 constrained SFT。
- 良性任务：Samsum、SQL Create Context、GSM8k，各 3 epochs；前两者效用为 ROUGE-1，GSM8k 为答案准确率（p.18，A.5.3）。恶意微调设置见 §4.2，本课题无需把它们纳入主训练条件。
- AdamW；Llama-2 lr 2e-5，Gemma lr 5e-6，batch 64；约束 SFT 前 10 步线性 warmup（p.17–18，A.5.1）。未从已读处确认这部分采用 LoRA，**不得标成 LoRA 实验**。
- 安全：HEx-PHI 的 330 条、11 类有害指令，GPT-4 判断是否产生有害输出；无攻击时称 harmfulness rate，有攻击时 ASR（p.3，§2.1）。

## 证据强度

Table 3（p.10）报告三轮 mean±std，支持特定模型/任务上的安全改善，但收益和效用代价并不统一：

| Llama-2 良性任务 | Standard SFT ASR / 效用 | Constrained SFT ASR / 效用 |
|---|---:|---:|
| Samsum | 23.4±2.5% / 51.7±0.5 | 3.2±0.8% / 50.1±0.2 |
| SQL Create Context | 15.4±1.4% / 99.1±0.2 | 3.2±0.8% / 98.5±0.1 |
| GSM8k | 3.3±0.4% / 41.7±0.4 | 2.0±0.5% / 37.4±0.3 |

初始 Llama-2 ASR 为 1.5±0.2%。GSM8k 的效用下降 4.3 个百分点，不能笼统归纳为“效用无损”。Gemma + Samsum 的 standard SFT ASR 2.0±0.2%，constrained 2.4±0.3%，说明此模型任务组合没有相同的显著退化/恢复空间。

附录 B（p.18）观察到良性任务最初 token 梯度更大，解释为原始模型固定客套前缀与下游直接答案开头不匹配；作者将它与安全退化的联系明确写为 **hypothesis**，不是已确定的唯一机制。

## 局限

- 主要研究 token 概率/梯度，未证明残差拒绝方向投影是退化的充分/必要解释。
- 同一方法在不同任务存在效用代价；标准差不等于对预注册非劣界限的证据。
- 安全恢复数据增强是在已有对齐模型上追加微调，因无法获取原始对齐训练管线，作者称该实现 inherently sub-optimal（p.17，Limitations）。
- 早期梯度与 warmup 影响应控制；本项目若比较，需记录公平训练预算和额外冻结参考计算。
- Qwen 适用性、LoRA 对应实现、本文代码的具体默认超参数仍待核验。无可引用的本项目人-机一致性证据。

## 与本课题关联

这是机制指导的训练时分布保护先行工作，也提供另一种解释：微调退化可能来自回答前缀/输出分布改变。若本课题发现拒绝方向下降，仅做相关分析不足以排除这一解释。需要在方法差异表明确本课题保护的是固定激活方向，并通过干预与随机对照检验方向特异性；不能声称首次在微调中保留安全表征或安全分布。
