## 方法重建

1. **方向**（p.4 §III-A）：每层在有害/无害指令的最后一个 prompt token 上做均值差，再单位化。本文方法段没有明确列出提取数据集名称、每类数量和与评测集的去重清单；复现前需澄清。
2. **机制量**（p.4 §III-B）：每个 checkpoint 重提取方向 `r_t`，跟初始 `r_0` 的夹角余弦比较。这是方向旋转量，不等于本 Brief 的“固定 r 上有害 prompt 投影下降”。论文把 `|cos θ|` 接近 1 解释为小漂移，但对拒绝语义来说方向符号翻转也重要；分析应保留有向符号。
3. **约束**（p.5）：对样本响应 token `j`、层 `l`，令 `z_t = r_l^T h_{t,l,j}`，约束 `||z_t-z_0||_2`，再对层与目标 token 求和、对样本取期望；总损失 `L_CE + α L_ProCon`。**排版公式是 L2 norm 下标 2，没有平方上标；不能直接转述为平方 MSE。** 训练公式的 `r_l` 没有时间下标，且以初始投影为参考，支持使用初始固定方向的读法；正文未明确写“每步冻结 r”，也未核验代码，所以冻结实现仍需复现时确认。
4. **增强**：ProCon-s 全程弱约束 α=0.1/0.2；ProCon-wu 先 α=1/2 强约束 warm-up，再无约束标准 IFT；再加 1,000 条 safety-oriented 样本得到增强版。p.10 报告 LLaMA2/3 warm-up 约4 epochs，Qwen2约16；加安全数据时通常减半。
5. **训练设置**（p.6）：标准 IFT 10 epochs、lr=2e-4。GSM8K 的扩展只在 LLaMA2 做（p.9）；另有混入100恶意样本的攻击设定，不能当作纯良性结果。

## 评价与结果的精确边界

- p.7 §IV-A3：UltraInteract 500 test samples 的任务准确率；安全是 AdvBench/CatQA 各110，SAP30/CompObj 各110，AutoDAN/PAIR 各50。
- 有害性分数 HS=1–5，由 GPT-Judge 判，脚注明确实际用 GPT-4o；ASR 是拒绝关键词规则，非 HarmBench 行为遵从判定器。两个指标不能互换。
- p.6 Table II：Qwen2-7B 的 vanilla / IFT / ProCon-wu-safe 的平均 ASR 分别为 18.91% / 69.09% / 17.58%，任务准确率为63.40% /75.00% /76.00%。这是作者当前组合设定结果，不能直接预言本项目 Qwen2.5 + Alpaca-only 的效应。
- p.8 §V-A/Fig.3：约束后重估方向更接近初始方向。该结果支持几何变化受干预影响，仍不足以单独证明“方向漂移是唯一或主要因果中介”。
- 已检查方法、全部结果/消融和附录：**未见报告**同范数随机方向锚定、提示级投影变化与行为翻转的 logistic 回归、多训练种子 CI、TOST 等价检验、正式过度拒绝集。此为本版本报告范围观察，非领域空白证明。

## 对本课题的影响

原 Brief C-1 中“无人研究微调拒绝方向变化”“无人把拒绝方向作为微调约束”均不能维持；**良性 LoRA + 机制追踪 + 激活投影训练锚定**已经直接重叠。只换 Qwen2→Qwen2.5、MSE→hinge、某一层、更多模型或随机方向对照，尚不足以自动构成新颖研究。

可以提交用户评审的窄化方案是：以 ProCon 为先行基线，做预注册的机制反证/复现，明确区分固定方向幅值、方向旋转、输出读出，并检验投影保持是否充分、是否特异。但 SDP（R-056）已进一步覆盖固定投影和提示相关性，必须合并审视；本卡**不授权改题、不证明扩展尚无人做**。
