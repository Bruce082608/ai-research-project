# R-054 — Llama Guard: LLM-based Input-Output Safeguard for Human-AI Conversations

- 作者：Hakan Inan、Kartikeya Upasani、Jianfeng Chi、Rashi Rungta、Krithika Iyer、Yuning Mao、Michael Tontchev、Qing Hu、Brian Fuller、Davide Testuggine、Madian Khabsa。

- 本地原文：[PDF](../原文/R-054_2312.06674v1.pdf)、[逐页文本](../原文/R-054_2312.06674v1.txt)。已读摘要、§2–§4.4、§6、附录 B。**本卡核验的是第一代 Llama Guard / Llama2-7b；不是 Llama Guard 2、3、4。** 未读取外部模型卡或运行模型。页码为 PDF 页码。

## 核心主张

将输入提示与模型回答的安全风险分类分别表述为指令任务，训练一个可通过提示调整分类体系的 LLM 安全审核器。它回答“内容是否违反给定政策”，不同于 HarmBench 的“回答是否执行指定行为”。

> “We provide different instructions for classifying human prompts (input to the LLM) vs AI model responses (output of the LLM).”（p.2，贡献列表）

> “First, the model should output ‘safe’ or ‘unsafe’, both of which are single tokens in the SentencePiece tokenizer that we use.”（p.3，§3.1；引号按转录统一）

## 方法

输入包含风险类别与说明、待分类角色、对话及输出格式。模型先输出 safe/unsafe；若 unsafe，下一行列类别。第一个 token 的概率可读作二元分类分数（p.3–4）。因此必须指定是 user prompt 还是 assistant response 分类，不能因请求有害就把安全拒绝回答也算有害。

初代训练政策有六类：Violence & Hate、Sexual Content、Guns & Illegal Weapons、Regulated or Controlled Substances、Suicide & Self Harm、Criminal Planning（p.2–3）。可用 zero/few-shot 提示适配其他政策，但不同政策并不天然可比；跨政策的基线 1-vs-benign 设置可能去掉难负例而使结果偏乐观（p.6，§4.1）。

## 数据与设置

- 从 Anthropic harmlessness 偏好数据取首条人类提示，内部 Llama 生成合作/拒绝回答；内部专家红队标注 prompt-category、response-category、prompt-label、response-label 四类字段。
- 清理后 13,997 组提示/回答，随机 3:1 划分训练与评估（p.4–5，§3.3）。未见原文报告此内部数据的人-人一致性数值。
- 底座 Llama2-7b，8×A100 80GB；batch2、sequence4096、lr2e-6、500 steps，约1 epoch（p.5，§3.4）。
- 外部测试：ToxicChat 10k、OpenAI moderation 1,680 prompt examples（p.6–7）。这些主要是提示审核，不直接替代本项目生成回答的行为评测。
- 主度量 AUPRC（unsafe 为正类）；附录 B 另以阈值 0.5 报 precision/recall/F1（p.7、p.14–15）。

## 证据强度

Table 2（p.8）Llama Guard AUPRC：内部 prompt0.945、内部 response0.953、OpenAI Mod0.847、ToxicChat0.626。**AUPRC0.953 不等于95.3%准确率或人类一致率**。

附录 B Table 5–6：内部 prompt 分类 P/R/F1=0.880/0.864/0.872；response 分类=0.900/0.867/0.884；阈值0.5。数字受原始内部政策与测试分布限定，不能直接赋给后续代次或 Qwen 输出。

与 R-053 交叉核验：HarmBench 的指定行为人工评测集上，初代 Llama Guard 平均一致率仅66.94%（R-053 p.18 Table3），这和本篇内部政策 AUPRC高并不矛盾，说明评测任务/政策必须一致。

## 局限

- 作者列出训练知识范围、英语为主、政策覆盖不完整、可能被提示注入影响等限制（p.10–11，§6）。
- 未核验“人类一致性85–90%”的通用说法；0.884 是内部 response F1，不是 agreement。
- 不能把初代模型的训练数据、风险类别、阈值、AUPRC/F1 复制到 Llama-Guard-3-8B。R-037 使用的恰是第三代，其具体 checkpoint、模型卡、提示模板和实测校准本轮仍待核验。
- 本轮按 G2 数据库范围只核验官方 arXiv 论文，模型卡外部页面未读取；若后续选第三代作为评测器，应先核验该代官方材料与版本。

## 与本课题关联

可作为“按风险政策的有害回答率”辅助度量候选；若主指标为指定有害行为遵从率，HarmBench 的定义更直接。必须同时冻结判定器代次、角色、政策、模板、输出解析、异常输出处理；本项目自己的人工抽检仍不可省略或由论文内指标替代。
