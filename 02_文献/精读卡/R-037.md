## 核心主张

**这是本课题最直接的已读先行工作之一。** 它已同时研究良性 LoRA 微调后的安全表征变化、训练中保持安全特征、以及安全与效用结果。不能把它仅归为“权重空间方法”而忽略其表示动机与测量。

> “In this paper, we first investigate the underlying mechanism by analyzing the changes in safety alignment related features before and after fine-tuning.”（p.1，摘要）

> “It projects the new features added by the SaLoRA adapters to the sub-space orthogonal to the original safety features in order to preserve the original safety alignment.”（p.2，Introduction）

## 方法

- §3.2（p.4）在原始模型特征上训练线性探针，再用同一探针分类不同 LoRA rank 微调模型的特征，观察安全场景识别准确率变化。特征包含有害提示及其安全响应；不是只从 harmful/harmless 提示均值差提取的单一拒绝方向。该段同时出现 MLP outputs、attention head output 等措辞，具体 hook 位置需代码核验，不能假定已明确。
- §4.1（p.5）令 `Xh` 为有害提示及其安全回答的层输入特征，对 `WXh` 做 SVD，取前 `rs` 个左奇异向量组成 `Uc`，固定 `Cs = I − UcUcᵀ`。它使新增 adapter 输出避开原始安全特征主子空间。
- §4.2–4.3（p.5–7）使用下游任务特征和权重 SVD 初始化 trainable A/B，并从原权重减去初始 `CsB0A0`，保证起始函数与原模型一致；训练中冻结 `Cs` 与剩余原始权重。保存时合并 `CsB`，另需存初始 adapter，作者报告 adapter 存储约普通 LoRA 的两倍。
- `rs=rt=32` 为正文主要设置；§5.7 再用线性探针评估 SaLoRA 后安全表征保持（p.10）。这已形成“观测 → 干预 → 再观测”结构，但不是训练中多检查点的拒绝方向—行为配对轨迹。

## 数据与设置

- 安全实验：Llama-2-chat-7B/13B、Llama-3.1-Instruct-8B、Mistral-7B-Instruct-v0.3，在 Alpaca 上 AdamW，lr 2e-4、1 epoch、batch 16（p.7）。
- 使用 AdvBench 有害提示的 70% 及其安全回答提取保护模块；其余 30% 安全评测。正文称约 300 条安全示例，未给可复用分割 ID，精确去重/划分需代码核验。
- 评测器明确为 **Llama-Guard-3-8B**；harmful rate 为它把回答标为 unsafe 的比例（p.7，§5.2）。不可拿 R-054 初代 Llama Guard 的模型指标当作这一代的验证结果。
- 效用：Llama-2-chat-7B 在 commonsense-15k 微调，8 项常识推理任务准确率（p.8，§5.3）；主安全实验与主效用实验不是同一 Alpaca checkpoint 的配对效用表。
- 资源：单 A100-80GB。对照 LoRA/DoRA/PiSSA，并配若干安全方法（p.7）。

常识任务 rank16：LoRA 平均准确率 59.2%、harmful rate 7.8%；SaLoRA 62.9%、0.0%（p.8，Table 2）。资源表在 **batch8 / r32 / Alpaca / 1 epoch** 条件下：LoRA 训练 2.95 h；SaLoRA 预处理 0.12 h、训练 2.98 h（p.9，Table 3）；不能当作本项目预计耗时。

## 局限

- 线性探针性能变化体现表征分布变化，单凭该观察不能证明安全特征改变是唯一原因；本文的理论也依赖“良性数据激活安全子空间”等假设（p.4–5，§3.3）。
- 有害率依赖 Llama Guard 3 的 unsafe 分类，未在已读正文报告人工抽检、一致性或置信区间。
- 70/30 单数据源分割可减少直接重合，但跨基准泛化、语义泄漏与具体分割仍待核验。
- 任务专用初始化是复合干预，必须与安全模块分开消融。§5.5 也报告移除新初始化时效用可能低于普通 LoRA。
- 不是“无超参数”：至少有安全 rank、任务 rank、LoRA rank。未看到 Qwen2.5、随机安全方向安慰剂、独立种子区间或单样本纵向行为翻转分析。

## 与本课题关联

本课题的新颖性必须缩窄到：预先冻结的**拒绝方向**而非整个高方差安全特征子空间；训练时显式方向投影锚定损失；独立数据上的纵向配对轨迹；随机方向/强度匹配/多方向对照。以上是需要验证的差异，不能直接宣称新颖。SaLoRA 应在差异表列为直接重叠；是否增加实现基线、改变研究叙事，应提交关卡决定，不能悄然改 Research Brief。
