## 1. 反漂移检查（3.6）

本里程碑服务于同一个研究问题：检验良性 LoRA 微调造成的安全退化是否伴随拒绝方向投影下降，并检验训练时方向锚定能否在效用损失很小的情况下恢复安全。检索只用于核验机制、基线、评测器和新颖性边界，不改变 Research Brief 的 RQ、H0/H1、主指标或数据分割。

## 2. 数据库与读取标准

| 数据库 | 用途 | 允许的读取深度 |
|---|---|---|
| arXiv API / arXiv 页面 | 精确编号核验、关键词发现、摘要与论文正文 | 读到摘要全文；纳入综述或差异表前尽量读方法/实验相关正文 |
| Semantic Scholar API | 交叉发现近作、引用网络和摘要 | 读到摘要与元数据；正文仍以论文原文为准 |
| ACL Anthology | 查找 ACL/EMNLP/Finding 等可能未以 arXiv 为主入口的工作 | 读到摘要全文，必要时读取 PDF 相关章节 |

来源限制：只使用上述数据库返回的论文页面/PDF/API 内容。搜索结果摘要未实际打开前不记为已核验。每篇纳入 `引文库.md` 前记录 arXiv/DOI、页码或章节和直接摘录句。
