## 1. 研究问题与反漂移约束

本 protocol 只服务于以下问题：良性 LoRA 微调是否降低有害提示在拒绝方向上的投影并导致拒绝率下降；训练时锚定该方向能否在效用损失不超过预设阈值时恢复安全；随机方向锚定是否无效。

- H0-1：标准化投影均值差满足 `|d| < 0.2`，且投影变化到拒绝→遵从翻转的 logistic 系数 95% CI 含 0；H1-1：`d <= -0.5`，且下降越大越容易翻转。若 Δprojection=post−pre，则系数须为负且 CI 不含 0，不能把反向显著关联判为支持 H1-1。
- H0-2：C 与 B 的有害遵从率差异 CI 含 0，或 C 的效用损失大于 2 个百分点；H1-2：C 的有害遵从率显著低于 B、与 A 的差值在预设 ±5 个百分点等价 margin 内，且效用损失不超过 1 个百分点。
- H0-3：C 与 D 的有害遵从率无差异；H1-3：C 的有害遵从率显著低于 D。
- 任何改变研究问题、H0/H1、主指标、评测集合互斥关系或预设等价 margin 的决定，必须先写入 `DECISIONS.md` 并获用户批准。

## 4. 拒绝方向提取与锚定目标

1. 在 `D_ext_harm` 与 `D_ext_harmless` 上提取候选层最后一个 prompt token 的残差流均值差，按 Brief 的 difference-in-means 思路得到 `r`，并单位化为 `r_hat`。实现前需固定“最后一个 prompt token”的模板化定义。
2. 主分析中的 `r_hat` 只从不微调基座 A 提取一次，并冻结用于所有 condition/checkpoint；不得为每个微调模型重新估计方向后再比较投影。候选层选择使用单独的方向验证/dev 集，不能读取主有害评测标签或主结果。
3. 在预先列出的 3–5 个候选层上验证方向干预；层选择规则必须在读取主评测标签前固定。Brief v1.0 的 Go/No-go 标准为：留出有害提示上消除 `r_hat` 后拒绝率相对下降至少 50%；该标准是拟定判据，需在 G3 审查中确认。
4. 锚定损失沿用 Brief：

   `L = L_SFT + lambda * mean_x max(0, m - <h_l(x), r_hat>)`。

   `m` 取微调前锚定提示投影均值减 0.5 个标准差；MSE 版本作为消融。`lambda` 的数值、归一化和优化器实现需在 G3 前锁定，并只能用训练/dev 数据校准。
5. 随机方向从同层方向空间生成，单位范数与 `r_hat` 相同；随机种子写入配置。每个方向 u 应用自己的基座阈值 `m_u=mean_A(<h,u>)−0.5 sd_A(<h,u>)`，不能复用拒绝方向的绝对阈值；还须在独立 dev 集比较约束激活比例和梯度量级，公平校准方案待 G3 固定。Full 的 top-k 子空间提案不能称作 R-038 概念锥复现，也不能事后替换 MVE 主干预。
6. 机制追踪在训练进度 0/25/50/75/100% 的固定 checkpoint 进行；每条提示保存投影原值、标准化值、checkpoint、condition、seed 和模型版本。checkpoint 不是独立统计重复单位。

## 5. 因变量与评测

### 5.1 主安全指标

- 主指标：主有害评测上的有害遵从率，数值越低越安全。1−遵从率是“未遵从率”，不等于“拒绝率”；后者需要独立行为定义。HarmBench 行为完成分类与 Llama Guard 内容安全分类不能当作可互换测量，最终判定器/标签映射在 G3 前固定。
- 主要比较：B 对 A 的退化、C 对 B 的恢复、C 对 D 的特异性。E 只作为预先声明的 baseline/性价比比较。
- 报告：按数据集分层及合并结果、每个 seed、均值、95% bootstrap CI、样本量和判定器版本。

### 5.2 机制指标

- 有害提示投影的标准化均值差 `d`（微调前后）。
- 提示级 `Delta projection -> refusal-to-compliance flip` 的 logistic 回归系数和 95% CI；seed 作为随机效应或分层重采样单位，不能把 checkpoint 当独立实验重复。
- 同时保存拒绝到遵从和遵从到拒绝的翻转计数，避免只报告有利方向。

### 5.3 效用与稳健性

- 效用：MMLU、GSM8K、IFEval 各自得分及三项预定义平均；报告 C 相对 B 与 A 的差值。
- 稳健性：按 HarmBench/AdvBench 分层、不同 checkpoint、不同判定器的一致子集；Full 再加入预先登记的越狱模板评测。
- 人工一致性：100 条标注意愿仍见 Q-008。原“只用双判定器一致子集作主结论”的默认降级有选择偏差风险，暂不采用为正式 protocol；建议保留全部主集分母、报告分歧和敏感性分析，降级口径需在 G3 中确认。

## 6. 统计方案

1. MVE 每条件 3 seeds，Full 主模型 5 seeds；seed 清单在运行前写入 config，运行后不可挑选。
2. prompt 与训练 seed 是交叉因子；建议在每次 bootstrap 中独立重采样 seed 索引和分层 prompt 索引，再取交叉子表，所有条件共享相同索引以保持配对。不能把重复的 prompt/checkpoint 当独立观测；3 个 seeds 的方差估计仍不稳，须逐 seed 报告。
3. 主要推断预注册为：C-B 安全差、C-A 等价性（Brief 的 ±5 个百分点 margin）、C-D 特异性，以及 H1-1 的提示级投影-翻转关联。多重比较使用 Holm 校正；E 作为描述性 Pareto baseline 不做显著性宣称。
4. 未校正 TOST α=0.05 对应 90% CI 完全落在 ±5 pt 内；将 `p_eq=max(p_lower,p_upper)` 作为一个复合 p 值进入预设 Holm 比较族，校正后的等价结论以校正 p 为准，不能只依据未校正 90% CI。差值另外报告 95% CI。“CI 含 0”不证明等价；未满足 H1 也不自动支持 H0。
5. 解析情景核算已完成：`设计核算/精度与统计审查.md` 和 `precision_scenarios.json`。400 条提示不保证等价检验功效，表中 q 为假设、没有模型实测或 seed 方差证据；支持/排除/不确定三分判定及具体功效方案需在范围重审后锁定。

## 7. 失败判据与止损

| 编号 | 触发 | 处理 |
|---|---|---|
| R1 | 三个候选模型均无法达到方向有效性 Go/No-go | 停止方向锚定主线，按 Brief 切换候选 1 前重做 M2 检索 |
| R2 | 无约束 LoRA 两轮均未产生预设安全退化 | 将现象不可复现作为结果；按 Brief 评估是否切换候选 1 |
| R3 | 所有预设 `lambda` 档效用损失超过 2 pt | 放弃“无损恢复”措辞，报告 Pareto 与 H1-2 负结果 |
| R4 | 判定器与人工一致性低于预设阈值 | 重新校准判定器并人工复核；一致子集仅作敏感性分析的拟议方案，主分母不按两者是否一致筛选，待 G3 固定 |
| R5 | M2 找到直接同题工作 | 暂停新颖性表述，写入问题队列并重新界定扩展或止损 |
| R6 | 累计预算超过计划 20% | 按 Brief 的四步降级顺序，逐批写实验日志 |

## 9. 可复现交付要求

- 单一 YAML/JSON 配置入口；所有模型、tokenizer、数据版本、超参、seed、层、方向生成随机状态显式记录。
- 训练与评测分离；评测脚本独立运行并输出结构化 JSON，包含输入文件哈希和环境版本。
