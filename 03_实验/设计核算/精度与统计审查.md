# 设计阶段精度与统计审查

> 2026-09-08。这是解析情景计算，不是模型实验结果，不计入 `results/`。原设定来源：Research Brief v1.0 §1.2、§3；数值由 Python `statistics.NormalDist` 与下述公式计算，输出见 `precision_scenarios.json`。

## 1. 400 条提示不能保证等价性检验的功效

设两条件在同一提示上的二分类差为 D∈{-1,0,1}，不一致概率 q=P(D≠0)，均值差 Δ=E(D)，则 Var(D)=q−Δ²。在独立提示且忽略训练 seed 方差的近似下，SE=sqrt((q−Δ²)/n)。

以下假设 Δ=0、n=400、等价界限 ±0.05；q 是人为设定的情景值，未从模型或论文估计。双单侧 TOST α=0.05 对应未校正 90% CI；普通差值另报告 95% CI。近似功效为 max(0,2Φ(0.05/SE−z₀.₉₅)−1)，80% 功效样本数约为 ceil(q×(z₀.₉₅+z₀.₉₀)²/0.05²)。

| 假设 q | 95% CI 半宽（百分点） | TOST 近似功效 | 80% 功效所需提示数（近似） |
|---:|---:|---:|---:|
| 0.05 | 2.19 | 99.5% | 172 |
| 0.10 | 3.10 | 87.1% | 343 |
| 0.20 | 4.38 | 44.6% | 686 |
| 0.30 | 5.37 | 14.4% | 1,028 |
| 0.50 | 6.93 | 0.0% | 1,713 |

数值字段：JSON `rows[].ci95_halfwidth * 100`、`approx_power_under_zero_difference * 100`、`approx_n_for_80pct_power`。0% 是固定标准误正态近似下接受区间为空，不是精确有限样本功效为零的断言。

**推断限制**：模型种子间差异、数据集重叠、语义近重复和多重检验均未纳入；表格不能证明实际设计达到上述功效。多个 seed 重复同一提示不能简单把 n 乘以 seed 数。需要先在独立开发集估计不一致率和种子方差，再评估是否能支持原等价性目标。

## 2. 原假设必须容许“证据不足”

Brief H0-1 的 |d|<0.2 与 H1-1 的 d≤−0.5 未覆盖中间区域；H0-2/H1-2 对 1～2 个百分点效用损失也未覆盖全部情况。“CI 包含 0”不是接受零效应的证据。不满足 H1 时，不得自动宣布 H0 成立；尤其不能据此得出“拒绝方向不是退化载体”。

建议在研究范围重新批准时把判定表写为：支持预设效应／排除预设最小效应／证据不足。原 H0/H1 数值在获批前保留，不以本审查擅自替换。

## 3. 配对与交叉重复

提示在全部 seeds 和条件中复用，prompt 与 seed 是交叉因子，不是每条 prompt 各有独立训练 seed。建议每次 bootstrap 独立重采样 seed 索引和（数据集内）prompt 索引，再取二者的笛卡尔子表；相同索引用于所有条件以保留配对。先按 seed 报告效应，不能只给合并 CI。

只有 3 个训练 seeds 时，seed 方差和尾部估计很不稳；5 个 seeds 也不能保证正态或可靠外推。checkpoint 用于轨迹分析，不算新实验重复；主机制检验预先指定最终 checkpoint，或明确时间项与聚类结构。

## 4. 不能把安全概念混成同一标签

有害行为是否被完成、是否出现拒绝语句、是否包含不安全内容是不同问题。主指标维持“有害遵从率”；拒绝率需独立行为定义；只有“未遵从率”才可机械计算为 1−遵从率。判定器之间不一致样本应保留在主分母中并做敏感性分析，不能只报告一致子集而隐去分歧比例。

## 5. 基线与预算的可核验约束

- A 若使用确定性解码，可评测一次并作为所有种子的共同配对基线；重复同一输出不会生成独立 seed 证据。
- E 替换 5% 样本只保证样本比例，不保证 token 相等。应同时记录样本、有效输入 token、监督 token、更新步数和实际耗时。若无法同时匹配，应报告预算差并设置适当敏感性分析，不能凭“替换”宣称已等预算。
- 随机方向锚定需使用各自方向的基线投影标尺，并报告约束激活比例/梯度量级。直接复用拒绝方向的阈值可能人为惩罚随机方向，造成无效安慰剂。
- “平均效用损失≤1 pt”是已批准假设；逐任务报告是透明度要求。擅自改成“每项≤1 pt”会改变成功标准，必须单独提案。
